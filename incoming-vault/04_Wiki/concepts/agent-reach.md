# Agent Reach

Agent Reach is a multi-platform research access layer for agents. On this machine, core channels are installed: GitHub, YouTube, V2EX, RSS, Exa semantic web search, Jina web reader, and Bilibili via bili-cli. OpenCLI is installed but needs the Chrome extension to unlock logged-in browser-session channels.
