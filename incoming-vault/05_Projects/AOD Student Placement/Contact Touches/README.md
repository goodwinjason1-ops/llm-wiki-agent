# Contact Touches

Use this folder to capture emails or calls that happen **around** an application, including:

- pre-application questions;
- introductions to named contacts;
- clarification emails about role duties, roster, outreach/in-house split, checks or placement suitability;
- manual emails Jayse sends himself;
- Ari-drafted emails awaiting approval;
- replies from hiring managers, placement coordinators or listed contacts.

Template:

```text
C:/Users/Kidsg/Documents/AI Second Brain/00_System/Templates/AOD Contact Touch Email Log.md
```

## Capture options

Jayse can give Ari visibility by:

1. forwarding/copying the sent email text into Telegram;
2. uploading/screenshotting the email;
3. once Gmail is connected, asking Ari to search/read the relevant thread;
4. telling Ari: “log this as a contact touch for [organisation/role]”.

Every contact touch should link back to an Application Package where possible.
