# Application Packages

One note per role, placement enquiry, or application.

Use template:

```text
C:/Users/Kidsg/Documents/AI Second Brain/00_System/Templates/AOD Application Package.md
```

Naming pattern:

```text
YYYY-MM-DD - Organisation - Role or Placement.md
```

Every package should track:

- source job ad / PD / screenshot
- ChatGPT draft materials
- Ari-reviewed/tailored materials
- approval status
- sent/applied status
- follow-up date
- dashboard update status

No email is sent and no application is submitted without Jayse approval.
