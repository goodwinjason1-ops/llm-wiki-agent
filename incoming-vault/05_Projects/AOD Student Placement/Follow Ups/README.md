# Follow Ups

Follow-up notes for placement enquiries and paid role applications.

Use template:

```text
C:/Users/Kidsg/Documents/AI Second Brain/00_System/Templates/AOD Application Follow-Up.md
```

Default follow-up windows:

- Placement enquiry: 5 business days.
- Paid role application: 7 calendar days, unless the ad says no contact.
- Closing date reminders: 3 days before and morning of deadline.

Once Google Calendar is connected, Ari can create/update calendar follow-up reminders only with Jayse approval unless explicitly instructed.
