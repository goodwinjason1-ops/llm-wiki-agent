# Manual TradingView Setup Guide — QTF-021

Risk mode: paper/research only.

## 1. Add strategy to TradingView

1. Open TradingView.
2. Open Pine Editor.
3. Paste one of:
   - `pine_strategies/tv_e01_bb_macd_rsi_momentum.pine`
   - `pine_strategies/tv_e02_ema_supertrend_macd.pine`
4. Click Add to chart.
5. Inspect visual entries/exits before trusting any metric.

## 2. Backtest checks

Record:

- symbol/timeframe;
- date range;
- net profit;
- max drawdown;
- trade count;
- profit factor;
- whether results survive adjacent symbols/timeframes.

## 3. Alert setup — paper only

Use TradingView alert condition from the strategy and message generated by the Pine `alert()` call.

Do not connect webhook to Bybit/Trigger Trade/live execution.

## 4. Paper ledger

Paste/export alerts into:

```text
ledgers/tv_paper_alerts.jsonl
```

Each line must match `alert_contracts/tv_alert_schema.json`.

## 5. Validate alerts locally

```bash
python validate_tv_alert.py alert_contracts/example_alert.json
python -m pytest tests -q
```

## 6. Promotion gate

A TradingView strategy can only move beyond research after:

- clean visual chart review;
- enough trades;
- paper alert ledger validates;
- costs/slippage included;
- drawdown acceptable;
- Jayse explicitly approves the next scope.
