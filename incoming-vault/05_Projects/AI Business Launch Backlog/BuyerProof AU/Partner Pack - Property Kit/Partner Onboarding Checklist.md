# Partner Onboarding Checklist

## Partner details

- [ ] Business name
- [ ] Partner type: broker / buyer's agent / conveyancer / building inspector / pest inspector / insurance broker / other
- [ ] Contact name
- [ ] Email
- [ ] Phone
- [ ] Website
- [ ] Booking link
- [ ] Logo file
- [ ] Preferred CTA
- [ ] Service area / state

## Compliance / safety check

- [ ] Partner understands checklist is educational only.
- [ ] Partner agrees not to remove disclaimers.
- [ ] Partner agrees not to add legal/financial/building/pest/insurance/tax advice claims.
- [ ] Partner has reviewed intro/footer wording.
- [ ] Any compliance concerns logged before distribution.

## Co-branded asset setup

- [ ] Add partner wrapper header.
- [ ] Add partner footer/bio.
- [ ] Add source checklist version and generated date.
- [ ] Export/send markdown or printable HTML/PDF.
- [ ] Partner confirms contact details and CTA.

## Distribution test

- [ ] Choose one distribution channel: email / socials / website / direct leads.
- [ ] Set 14-day start date.
- [ ] Track downloads/replies/bookings/questions.
- [ ] Review on day 14.

## Day-14 review questions

1. Did people download/open/use it?
2. Did it create replies or bookings?
3. What confused buyers?
4. What wording made the partner nervous?
5. Would the partner pay for an improved version or ongoing content/checklists?
6. Should this become a paid setup, monthly content offer, or stop?
