# create-buyerproof-kit-skill

Use this skill to create a new BuyerProof AU product kit.

## Inputs required

- Product category
- Target buyer
- Expensive decision or stressful life-admin moment
- Known professional handoffs
- Australian context requirements
- Intended monetization: free checklist, paid kit, B2B co-branded lead magnet, or concierge support

## Steps

1. Define the target buyer and the expensive decision.
2. Define the costly mistakes/red flags the kit helps users avoid.
3. Write the safety disclaimer before the checklist.
4. Identify official/professional checks and handoffs.
5. Create checklist sections in the order the buyer experiences the decision.
6. Create a tracker/spreadsheet schema.
7. Create scripts/questions for agents, sellers, providers, or professionals.
8. Create red/yellow/green risk scoring.
9. Create a final decision-support section that never makes the decision for the user.
10. Create landing page copy and 5 launch posts.
11. Create a B2B co-branded lead magnet angle.
12. Run safety-review-buyerproof-kit-skill before marking done.
13. Run extract-approach-skill if the work involved meaningful judgement.

## Required files

- `Product Kits/[Kit Name] v1.md`
- `Spreadsheets/[Kit Name] Tracker.csv`
- `Landing Page Copy - [Kit Name].md`
- `5 Launch Posts - [Kit Name].md`
- Optional: `Outreach/[Kit Name] Partner Outreach.md`

## Quality bar

The kit is not complete unless it has disclaimer, checklist, tracker, scripts, red flags, professional handoff, final decision support, and launch path.
