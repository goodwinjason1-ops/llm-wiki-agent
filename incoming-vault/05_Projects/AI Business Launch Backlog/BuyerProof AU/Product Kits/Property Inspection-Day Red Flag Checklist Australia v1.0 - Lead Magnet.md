# Property Inspection-Day Red Flag Checklist Australia

## BuyerProof AU — Check before you commit

Use this one-page checklist at an open home or private inspection to spot what needs follow-up before you make an offer, bid, or go unconditional.

## Important disclaimer

This is an educational preparation checklist only. It is **not** legal, financial, investment, building, pest, insurance, tax, or property advice. It does not tell you whether to buy a property. Always verify concerns with qualified professionals: conveyancer/solicitor, building inspector, pest inspector, broker/lender, insurer, council/local authority, and strata/body corporate specialists where relevant.

Rules, costs, contracts, cooling-off periods, auction conditions, zoning, disclosures, and professional requirements vary by state/territory and sale type. **Verify locally and professionally.**

---

## 1. Before you leave home

- [ ] Budget and maximum price written down.
- [ ] Finance/pre-approval status understood with lender/broker.
- [ ] Conveyancer/solicitor chosen or shortlisted.
- [ ] Building and pest inspector shortlist ready.
- [ ] Sale type checked: auction / private treaty / EOI — verify what this means locally.
- [ ] Phone charged for photos, notes, torch, and mobile reception test.
- [ ] Non-negotiables written down: suburb, rooms, parking, condition, strata/freestanding, commute, school/work needs.

## 2. Inspection-day red flags to photograph or ask about

| Area | Red flags / follow-up items | Notes |
|---|---|---|
| Roof/gutters | sagging, broken tiles, rust, overflow stains, blocked drainage |  |
| Walls/ceilings | cracks, stains, fresh patch paint, sagging, bubbling |  |
| Floors | slope, bounce, soft spots, water damage, uneven tiles |  |
| Bathrooms/laundry | mould, poor ventilation, leaks, swollen cabinetry, low water pressure |  |
| Kitchen | leaks, damaged cabinetry, appliance age, ventilation, power points |  |
| Windows/doors | sticking, gaps, rot, cracked glass, security concerns |  |
| Drainage/site | water pooling, slope toward house, damp ground, retaining walls |  |
| Electrical visible | old switchboard, few outlets, flickering lights — professional check required |  |
| Noise/location | roads, trains, flight path, neighbours, dogs, nightlife |  |
| Internet/mobile | test reception; check NBN/provider availability if important |  |

## 3. If it is a unit/townhouse/strata property

- [ ] Ask about strata/body corporate levies.
- [ ] Ask if there are current or proposed special levies.
- [ ] Ask whether strata records can be reviewed by a professional.
- [ ] Look for visible common-area defects: cracking, leaks, concrete spalling, poor maintenance.
- [ ] Check parking/storage: is it on title, allocated, leased, or common property? Verify professionally.
- [ ] Photograph notice boards/common areas if allowed.

---

## 4. Questions to ask the agent

- Why is the vendor selling?
- How long has it been on the market?
- Are there known defects or issues disclosed by the vendor?
- Have there been insurance claims, flooding, storm damage, or major repairs?
- Have there been extensions, renovations, or unapproved-looking works?
- Are approvals/permits/certificates available for renovations? Verify with your conveyancer/council.
- Are there easements, covenants, shared access, or boundary issues? Verify professionally.
- For strata: are there special levies, disputes, defects, or major works planned?

---

## 5. Before making an offer or bidding

- [ ] Contract reviewed by conveyancer/solicitor.
- [ ] Finance status and key dates confirmed with lender/broker.
- [ ] Building and pest inspection plan in place where possible.
- [ ] Insurance quote considered.
- [ ] Strata/body corporate records reviewed if applicable.
- [ ] Council/zoning/approval questions identified for professional follow-up.
- [ ] Walk-away price and walk-away conditions written down.
- [ ] Anything unknown is treated as **unknown**, not as a pass.

---

## 6. Decision support

This checklist does **not** decide for you. Use it to decide what needs checking next.

- [ ] Continue researching.
- [ ] Ask agent/vendor more questions.
- [ ] Get conveyancer/solicitor review.
- [ ] Book building/pest inspection.
- [ ] Check finance/insurance.
- [ ] Slow down or walk away until key unknowns are resolved.
