# Safety Review — Used-Car Buyer Inspection Kit Australia v1

## Verdict

**Pass for feedback / draft sharing. Not yet final public/legal/commercial publish.**

The kit is framed as an educational preparation tool and repeatedly tells users to verify with official/professional sources. It does not claim to replace a mechanic inspection.

## Checks completed

- [x] Educational-only disclaimer near the top.
- [x] States it is not mechanical/legal/financial/professional advice.
- [x] Recommends PPSR.
- [x] Recommends state/territory rego checks.
- [x] Recommends independent pre-purchase inspection by qualified mechanic.
- [x] Avoids guaranteeing vehicle condition, safety, title, or reliability.
- [x] Uses decision-support language rather than telling user to buy/walk away.

## Required before public launch

- [ ] Have one qualified mechanic/pre-purchase inspector review wording.
- [ ] Add state/territory registration check links or a "choose your state" resource section.
- [ ] Confirm PPSR wording is current before publishing.
- [ ] Add version/date and update process.
- [ ] If selling, add refund/contact/support details and commercial terms.

## Risky wording to avoid in marketing

| Avoid | Safer replacement |
|---|---|
| "Avoid buying a bad car" | "Reduce avoidable mistakes before buying" |
| "Know if a car is safe" | "Know what to ask a qualified mechanic" |
| "Complete inspection" | "Buyer preparation checklist" |
| "Guarantee no finance/write-off problems" | "Remember to run PPSR and verify documents" |

## Professional handoff requirements

Every public page for this kit should include:

- PPSR link,
- state/territory rego check reminder,
- independent mechanic inspection reminder,
- insurance quote reminder,
- no-guarantee language.
