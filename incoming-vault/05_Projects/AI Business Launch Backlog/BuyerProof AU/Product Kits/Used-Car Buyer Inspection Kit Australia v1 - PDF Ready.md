# Used-Car Buyer Inspection Kit Australia

## Check before you commit

A practical checklist, tracker, seller script pack, and negotiation worksheet for Australians buying a used car privately or from a dealer.

## Who this is for

Use this kit if you are:

- buying your first used car,
- helping a family member buy a car,
- inspecting cars from Facebook Marketplace, Carsales, Gumtree, or dealers,
- comparing multiple cars,
- trying to avoid finance owing, written-off/stolen history, hidden damage, odometer concerns, or surprise repair costs.

## Important disclaimer

This kit is an educational preparation tool only. It is not mechanical, legal, financial, safety, or professional advice. It is not a substitute for an independent pre-purchase inspection by a qualified mechanic. It cannot guarantee a vehicle’s condition, title status, safety, roadworthiness, value, or future reliability.

Always verify details using current official/professional sources before buying.

## Official / professional checks to consider

- **PPSR** — Personal Property Securities Register: https://www.ppsr.gov.au/
- **State/territory registration check** — use your relevant road authority / transport department (see list below).
- **Pre-purchase mechanical inspection** — use a qualified independent mechanic or inspection service.
- **Insurance quote** — check whether the car can be insured at a price you can afford.
- **Roadworthy / safety certificate requirements** — vary by state/territory and sale type; verify locally.

If any official check or professional advice conflicts with this kit, trust the current official/professional source.

## Where to run a registration check

Each state and territory offers a registration check through its official road/transport authority. Search "registration check" on the official site for the state or territory where the car is registered. Names and processes change — verify locally before relying on results.

| State/territory | Authority to search for |
|---|---|
| NSW | Service NSW |
| VIC | VicRoads |
| QLD | Department of Transport and Main Roads |
| WA | Department of Transport WA |
| SA | Service SA / EzyReg |
| TAS | Service Tasmania |
| ACT | Access Canberra |
| NT | Motor Vehicle Registry (MVR) |

## Slow down if

- seller refuses VIN or rego,
- seller refuses inspection,
- seller pressures you to pay a deposit immediately,
- service history is missing without explanation,
- story changes between listing and messages,
- seller says “just needs a fuse/sensor/service” but will not verify.

# 4. Exterior inspection checklist

Inspect in daylight and dry weather where possible.

| Area | What to check | Notes |
|---|---|---|
| Panels | mismatched paint, uneven gaps, dents, rust, overspray |  |
| Bumpers | cracks, loose fitment, impact damage |  |
| Bonnet/roof/boot | hail damage, fading, rust |  |
| Doors | open/close smoothly, alignment, seals |  |
| Glass | windscreen chips/cracks, tint issues |  |
| Lights | headlights, brake lights, indicators, fog lights |  |
| Tyres | tread, age, uneven wear, matching set |  |
| Wheels | gutter rash, cracks, missing nuts |  |
| Underbody visible areas | leaks, rust, impact marks |  |
| Towbar/modifications | wiring, wear; ask your insurer and road authority whether modifications affect cover or compliance — verify locally |  |

## Exterior slow-down triggers

- uneven tyre wear,
- different paint shade between panels,
- rust in structural-looking areas,
- water/flood signs,
- poor panel alignment,
- fresh paint or heavy detailing hiding damage.

# 8. Test-drive checklist

Only test drive if safe, legal, and allowed. Bring another person if possible.

| Test | What to notice | Notes |
|---|---|---|
| Steering | pulls left/right, vibration, clunks |  |
| Braking | straight stop, no pulsing/squeal |  |
| Acceleration | hesitation, smoke, misfire |  |
| Gearbox | smooth shifts, no slipping/clunks |  |
| Suspension | knocks over bumps |  |
| Temperature | stays normal |  |
| Reverse/parking | camera/sensors, clunks |  |
| Highway speed if safe | vibration, tracking, wind noise |  |
| Low-speed turns | clicking, binding, steering noise |  |

## Test-drive slow-down triggers

- overheating,
- smoke under acceleration,
- clunking gearbox,
- brake vibration,
- steering pull,
- warning lights during drive,
- seller controls the route to avoid normal driving.

# 10. Mechanic inspection handoff questions

Ask the mechanic or pre-purchase inspector:

- Are there signs of previous accident repair?
- Are there oil, coolant, transmission, or differential leaks?
- Are there suspension, brake, steering, or tyre concerns?
- Are there diagnostic fault codes?
- Is the odometer/service history consistent?
- Are there signs of overheating?
- Are there upcoming major service items?
- What repairs are urgent vs later?
- Is the car safe/roadworthy based on your inspection?
- What would you estimate immediate repair costs to be?
