## Decision rule

Prioritized opportunities that are:

1. Fast to launch with low capital.
2. Clear buyer and pain point.
3. Service-first or productized-service first, so cash can arrive before building a full SaaS.
4. Compatible with Jayse's AI/Codex/Hermes/quant direction.
5. Defensible through niche, data, workflow, or recurring monthly value.

Deprioritized:
- Pure faceless-content plays with algorithm risk.
- Generic “make money with AI” videos without a narrow buyer.
- Anything implying questionable compliance, account misuse, insider trading, or unrealistic live-trading claims.

## Recommended first build: Local AI Receptionist + Website Conversion Package

Reason: fastest path to revenue, easiest to explain, and reusable across niches.

### Target niche shortlist

Start with niches where missed calls/bookings are expensive and owners are reachable:

1. Dentists / cosmetic dental.
2. Physios / chiropractors / allied health.
3. Med spas / cosmetic clinics.
4. Plumbing/HVAC/electricians.
5. Mortgage brokers / buyer agents.

### Initial offer

**AI Receptionist + Talking Website Starter**

- One-page landing/booking site or conversion upgrade to existing site.
- Voice/chat agent trained on FAQs, services, pricing ranges, hours, location, intake questions.
- Lead qualification and appointment request capture.
- CRM/Google Sheet/GoHighLevel-style pipeline.
- Missed-call text-back automation.
- Weekly lead report.

Pricing test:

- Setup: **A$750–A$2,500** depending on complexity.
- Monthly: **A$299–A$799/mo** for hosting, updates, reports, and automation maintenance.
- Optional performance kicker for booked qualified appointments after trust is established.

## 14-day launch plan

### Days 1–2 — Pick niche and build demo

- Choose one vertical, preferably dentists or local home services.
- Build one demo site page and one demo AI receptionist flow.
- Create a simple before/after ROI story: missed calls, unqualified leads, slow responses.
- Record a 60–90 second Loom demo.

### Days 3–4 — Build outreach list

- Scrape/find 100 local businesses in the chosen niche.
- Capture: business name, website, phone, owner/manager if available, email/contact form, obvious website issues.
- Score leads by bad website, no online booking, slow/unclear contact path, good revenue potential.

### Days 5–7 — Personalized outreach sprint

- Send 30–50 personalized emails/contact-form messages.
- Call 10–20 highest-fit businesses.
- Offer a free “missed-lead audit” or a custom mini-demo using their website/services.
- Goal: 3–5 discovery calls.

### Days 8–10 — Close first pilot

- Pilot terms: low setup or discounted first month in exchange for testimonial/data.
- Keep scope narrow: FAQ + booking request + CRM notification + weekly report.
- Do not promise autonomous medical/legal advice; agent should qualify and route.

### Days 11–14 — Deliver pilot and package proof

- Install widget/phone workflow or standalone demo page.
- Test all paths manually.
- Track leads, handoffs, call summaries, failed intents.
- Turn outcome into a case study and repeat outreach.

## Backtesting playlist assessment

Source: `How to Backtest ANY Trading Strategy with Backtesting.py (TRADERS CHEAT CODE)` by Moon Dev.

Useful parts for the quant project:

- Uses `backtesting.py` as a simple Python backtest framework.
- Demonstrates the `Strategy` class with `init()` for indicators and `next()` for per-bar logic.
- Shows using historical OHLCV data, running `Backtest(...).run()`, printing stats, and plotting.
- Includes conservative thinking around commission: he uses a higher-than-normal commission assumption to avoid fragile results.
- Demonstrates optimization over an SMA parameter range.
- Shows why bad tests are still useful: one example underperforms buy-and-hold and should be rejected/revised.

Cautions:

- The video's example is educational, not production-grade.
- Optimizing on the same full dataset is overfit-prone.
- Need to add slippage, next-bar fills, no lookahead, train/test split, walk-forward, and Bybit crypto data support.
- For Jayse's quant floor, this is best used as a quick **strategy-intake smoke-test engine**, not the final institutional-grade backtester.

Recommended quant integration:

1. Create `backtesting.py` smoke-test template for any strategy extracted from videos.
2. Default capital: **$5,000**.
3. Crypto data: prefer **Bybit public klines**.
4. Include fees/slippage by default.
5. Output: final equity, total return, max drawdown, Sharpe, exposure, trade count, win rate, profit factor, buy-and-hold comparison.
6. Add Monte Carlo/bootstrap forecast only after a strategy has a realistic return stream.
7. Promote only to read-only/paper monitor after out-of-sample and walk-forward evidence.
