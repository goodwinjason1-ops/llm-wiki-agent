# Demo Build Checklist

## Recommended demo source

Use one of Jayse-owned source sets:

- Business Context Brain demo pack;
- BuyerProof AU property partner pack;
- Basketball Coach Game Plan Pack.

## Build steps

- [x] Select one source folder or note cluster.
- [x] Capture the “before” state: messy source list / scattered notes.
- [x] Extract buyer/client questions.
- [x] Create source map.
- [x] Draft one lead magnet outline.
- [x] Draft 5 posts.
- [x] Draft 3–5 email follow-up sequence.
- [x] Create before/after screenshot spec.
- [x] Create a short walkthrough script.
- [x] Add to outreach as proof sample.

## Demo artifact structure

```text
Source-to-Revenue Demo/
├─ Before - Source Inventory.md
├─ Source Map.md
├─ Buyer Questions.md
├─ Lead Magnet Outline.md
├─ 5 Proof Posts.md
├─ 5 Email Follow Up Sequence.md
├─ Before After Walkthrough.md
└─ Demo Notes.md
```

## Demo quality bar

A prospect should understand within 60 seconds:

1. what raw material went in;
2. what usable assets came out;
3. how this could help them sell/educate/follow up;
4. what they would get in the paid Proof Pack.
