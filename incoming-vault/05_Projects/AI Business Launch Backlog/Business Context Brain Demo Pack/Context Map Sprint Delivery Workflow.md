# Context Map Sprint Delivery Workflow

## Phase 1 — Scope and intake

1. Pick one bounded business area.
2. Collect 20–200 files.
3. Remove or redact secrets/sensitive material.
4. Agree on desired output: vault, dashboard, templates, AI context pack.

## Phase 2 — Inventory

1. Count files and file types.
2. Classify docs: quote, SOP, project, client, supplier, policy, meeting, brainstorm, asset.
3. Flag sensitive files and unreadable files.
4. Create source inventory note.

## Phase 3 — Source summaries

For each high-value source:

- what it is,
- who/what it relates to,
- reusable knowledge,
- decisions/risks/actions,
- links to related notes.

## Phase 4 — Wiki/context map

Create pages for:

- services/products,
- clients/project types,
- processes,
- suppliers/tools,
- recurring questions,
- decisions,
- risks,
- templates.

## Phase 5 — Dashboards

Create:

- Start Here dashboard,
- key area dashboard,
- open questions/TODOs,
- AI assistant context note.

## Phase 6 — Templates

Create templates for:

- quote summary,
- project note,
- SOP,
- meeting note,
- decision log,
- source summary.

## Phase 7 — QA

- [ ] No secrets included.
- [ ] Raw/source docs linked.
- [ ] Key notes have frontmatter.
- [ ] Dashboard links work.
- [ ] Uncertain claims marked TODO verify.
- [ ] Client can understand the vault without the builder present.

## Phase 8 — Handoff

- Walkthrough video.
- Maintenance workflow.
- Suggested next 30 days.
- Optional monthly support offer.
