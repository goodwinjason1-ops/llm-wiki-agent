# Pilot Delivery Checklist — Renovator Quote Brain

## Scope

Pilot input: 20–50 redacted/anonymised documents from one quote/project area.

Acceptable inputs:

- quote PDFs,
- Word/Google Docs scopes,
- supplier PDFs,
- follow-up emails/SMS examples,
- project notes,
- variation notes,
- selected photos if helpful,
- checklists/templates already used by the business.

Do not request:

- passwords,
- live account access,
- bank details,
- private client identity details,
- API keys,
- unredacted sensitive commercial information unless necessary and explicitly approved.

## Intake checklist

- [ ] Confirm business type and main job categories.
- [ ] Confirm pilot folder scope.
- [ ] Confirm what can/cannot be used.
- [ ] Ask client to redact names, addresses, emails, phone numbers, and prices if preferred.
- [ ] Ask for 3 "good quote" examples and 1–2 "problem quote" examples if available.
- [ ] Ask for common customer objections or variation issues.
- [ ] Confirm delivery format: Markdown/Obsidian, Google Docs, Notion, or PDF pack.

## Extraction checklist

For each document, extract:

- [ ] job type,
- [ ] scope sections,
- [ ] reusable wording,
- [ ] inclusions,
- [ ] exclusions,
- [ ] allowances,
- [ ] variation triggers,
- [ ] supplier/material references,
- [ ] customer questions/objections,
- [ ] follow-up wording,
- [ ] missing information or ambiguity.

## Build checklist

Create:

- [ ] Quote Brain dashboard,
- [ ] reusable scope snippet library,
- [ ] inclusions library,
- [ ] exclusions library,
- [ ] variation/risk checklist,
- [ ] follow-up templates,
- [ ] onboarding note for admin/estimators,
- [ ] AI quote review prompt,
- [ ] source inventory,
- [ ] "how to keep this updated" workflow.

## Quality checks

- [ ] No private client names/addresses exposed in demo outputs.
- [ ] No prices shown unless explicitly approved.
- [ ] No compliance/legal/building advice presented as authoritative.
- [ ] Risk notes are framed as prompts/checks, not professional certification.
- [ ] AI prompt instructs model not to invent prices or compliance claims.
- [ ] Deliverables are useful without needing a chatbot.

## Walkthrough call agenda

1. Show before/after folder story.
2. Walk through dashboard.
3. Show quote snippet reuse.
4. Show inclusions/exclusions library.
5. Run one old quote through risk checklist.
6. Show follow-up template.
7. Show AI quote review prompt.
8. Ask: "What would make this useful enough to use weekly?"
9. Offer next step: standard sprint or monthly maintenance.

## Post-pilot upsell paths

| Need discovered | Upsell |
|---|---|
| more old quotes to process | Full Quote Brain Sprint |
| team needs ongoing updates | Monthly Brain Maintenance |
