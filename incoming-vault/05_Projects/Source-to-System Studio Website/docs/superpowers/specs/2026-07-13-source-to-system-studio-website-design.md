# Source-to-System Studio Website Design

## Approved direction

A small multi-page static offer hub using the public name **Source-to-System Studio**. `Source2Systems` may be used for a domain or social handle if available, but is not the display brand.

## Purpose

Give prospective business clients one credible link explaining the offers, process, proof boundaries, privacy/access controls and next step.

## Pages

- `index.html` — homepage and offer overview
- `offers.html` — detailed offer cards and service ladder
- `how-it-works.html` — discover → audit → map → implement → review
- `proof.html` — sanitised examples and private pilot pathways
- `contact.html` — qualification form and contact CTA

## Content rules

- Use approved Source-to-System Studio copy.
- Treat the financial-planner and wholesale doors/windows businesses as potential private pilots, never public testimonials.
- Include Local Visibility & Reputation Operations and Measurement & Growth Intelligence.
- Do not guarantee rankings, traffic, revenue or automation outcomes.
- State that clients retain ownership and named manager permissions are used.

## Visual system

- Warm off-white background; graphite text; restrained teal accent.
- Editorial hierarchy, fine-line process diagrams and purposeful cards.
- No purple gradients, excessive rounded cards or generic AI imagery.
- Responsive at 320px, 768px, 1024px and 1440px.
- WCAG-oriented contrast, semantic headings and keyboard-accessible navigation.

## Conversion path

Primary CTA: `Start a conversation`.
Contact form fields: name, business, email, business type, current problem, relevant offer, approximate document/content volume and preferred next step. Version one uses a static form/mailto placeholder; no external submission or credentials are configured.

## Proof model

Use three clearly labelled examples:

1. Business knowledge map for a document-heavy professional service.
2. Local visibility/profile audit for a local business.
3. Quote/SOP extraction workflow for a wholesale supplier.

These are demonstration/pilot concepts, not claimed client results.
