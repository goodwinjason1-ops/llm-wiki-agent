## Funnel map

```text
Traffic/outreach
  ├─ BCB cold outreach → landing page → demo walkthrough → client intake → Context Map Sprint
  ├─ BuyerProof property partner outreach → one-pager → co-branded checklist → partner onboarding → referral loop
  └─ Used-car/property lead magnets → feedback capture → kit sale or B2B partner proof

Delivery
  Client docs → inventory → raw source preservation → source summaries → wiki/process pages → dashboard → walkthrough video → monthly maintenance

Retention
  Monthly Brain Maintenance → new-source ingestion → dashboard refresh → missed-connection review → upsell Quote/SOP/AI Staff Assistant packs
```
