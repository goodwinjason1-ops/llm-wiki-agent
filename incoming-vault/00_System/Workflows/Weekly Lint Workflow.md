# Weekly Lint Workflow

1. Read `SCHEMA.md`, `index.md`, and recent `log.md`.
2. Scan for broken wikilinks, orphan pages, missing frontmatter, missing index entries, and pages >200 lines.
3. Check raw source sha256 values.
4. Produce a short report and create/update `04_Wiki/queries/vault-health-YYYY-MM-DD.md` if useful.
5. Append to `log.md`.
