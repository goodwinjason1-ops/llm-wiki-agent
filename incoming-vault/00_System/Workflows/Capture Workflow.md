# Capture Workflow

1. Put raw thought/link/file in `01_Inbox/` or `02_Raw/`.
2. Determine whether it is a source, project, area, resource, workflow, or skill.
3. Create/update the correct note with YAML frontmatter.
4. Add wikilinks to at least two related pages.
5. Update `index.md` and `log.md`.

Use when processing loose notes, links, ideas, or tasks.

## Inbox templates

Use [[Inbox Capture Template Guide]] for quick capture. Templates live in `00_System/Templates/` and are available through Obsidian's core Templates plugin.

For Telegram capture, use [[Telegram Quick Capture Workflow]]. The current safe trigger is plain text `cap` or `capture`; avoid `/cap` until it is registered as a real Hermes/Telegram command. Ari should prompt the missing fields rather than requiring Jayse to memorise them.
