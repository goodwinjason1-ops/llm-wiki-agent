# Skill Improvement Workflow

1. After a repeated or difficult task, write down what worked.
2. If it is Hermes-procedure knowledge, create/update a Hermes skill.
3. If it is project/personal knowledge, create/update an Obsidian workflow or skill note.
4. Next time the workflow is used, patch the instructions with any pitfalls discovered.
5. Keep one canonical workflow per recurring task to avoid skill sprawl.
