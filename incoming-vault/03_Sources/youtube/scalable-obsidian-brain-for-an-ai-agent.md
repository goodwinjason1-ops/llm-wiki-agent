# Scalable Obsidian brain for an AI agent

## Summary
Shows Obsidian as a persistent markdown memory layer for an AI agent. Store the vault locally or in a synced drive, give the agent the vault path, let it build folder maps, capture rules, security rules, indexes, and linked notes that compound over time.

## Implementation takeaways
- Treat video mentions of Claude as **Codex** for this user's setup unless a technical distinction matters.
- Prefer filesystem-first markdown notes in Obsidian so Hermes/Codex can read, edit, diff, and improve the system.
