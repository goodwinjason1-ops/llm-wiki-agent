# Hermes AI Trading Floor System

## Source

- Video: https://youtu.be/MbfuJZZ01IU
- Raw transcript: [[MbfuJZZ01IU]]

## Core idea

The video proposes using Hermes as an always-on AI trading research floor connected to Telegram, where different Telegram topics act as separate quant desks. Each desk has a specialized mission: build strategies, backtest them, optimize them, journal forward tests, and learn from failures.

## System components from the video

1. **Hermes Agent** — persistent agent with memory/self-improvement.
2. **Telegram bot + group topics** — each topic becomes an “office” or desk.
3. **Trader Dev MCP** — external tool for TradingView/Pine Script strategy building and backtesting. The exact install command is hidden behind trader.dev account/workbook access.
4. **Quant dashboard** — tracks strategies, iterations, performance, forward-testing notes, and indicator usefulness.
5. **Self-improvement loop** — schedule repeated research/backtesting tasks; save lessons as memory/skills/workflows.

## Limitations

The video repeatedly references a workbook and links in the description, but the transcript and public search did not expose the actual workbook contents. The strategy specs in this vault are therefore **clean-room reconstructions** from the video concepts, not copies of the hidden workbook.

## Safety stance

No autonomous live trading until a strategy has passed paper trading, walk-forward validation, risk checks, and explicit human approval.
