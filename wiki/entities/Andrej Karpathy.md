# Andrej Karpathy

> Author of the original LLM Wiki gist that this vault's structure is built on.

## Summary

Relevant to this vault as the originator of the [[LLM Wiki]] pattern: the proposal
that an LLM should incrementally maintain a persistent, interlinked markdown
knowledge base rather than repeatedly retrieving raw chunks.

## Key claims

- Authored the original LLM Wiki gist describing the three-layer / three-operation pattern ^conf:0.9 — source: `karpathy-llm-wiki`
- Framed the pattern's core insight as the maintenance asymmetry between humans and agents ^conf:0.8 — source: `karpathy-llm-wiki`
- Connected the pattern back to Vannevar Bush's Memex as prior art ^conf:0.7 — source: `karpathy-llm-wiki`
